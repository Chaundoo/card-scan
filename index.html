Live comps helper

This site can't read TCGplayer or eBay pages by itself; browsers block that. The free helper script fills that gap. When you tap Open & read, the page opens in a new tab, the helper reads the sales and listings you see there, and sends them back here. Nothing goes to a server and nothing is saved on this site.

iPhone (Safari)

  1. Install the free Userscripts app from the App Store.
  2. Settings → Safari → Extensions → Userscripts → turn it on and set All Websites to Allow.
  3. In Safari, open the helper script, tap the aA / puzzle icon → Userscripts → Install.
  4. Use this site in a Safari tab, not as a home-screen app (extensions don't run in home-screen apps).

Android

  1. Use Firefox and add the Tampermonkey add-on (Chrome on Android doesn't run extensions).
  2. Open the helper script and tap Install.

Computer

  1. Add Tampermonkey to Chrome, Edge or Firefox, then open the helper script and click Install.

No helper? Every source box also has a Paste option: open the page, select all, copy, and paste it in. The numbers come out the same.
